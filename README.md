# Cash Flow & Entrepreneurship Planner

**Build, don't bleed.**  
*Cash Flow. Creative Capital. Sustainable Growth.*

An interactive, offline-first budgeting tool for personal cash flow, scenario modeling, and entrepreneurial planning.

## Features

- Adjustable income and expense assumptions
- Monthly cash-flow projections
- Optional extra-income and realized trading-bonus scenarios
- Reusable planning variables
- CSV results and JSON settings exports
- Print-friendly reporting
- Runs locally in a modern browser without an account or backend

## Getting started

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Adjust the assumptions to match your circumstances.
4. Export results as CSV or settings as JSON when useful.

The standalone planner can run offline after it has been saved locally. Features that depend on GitHub Pages or other hosted services require internet access.

## Project philosophy

Protect essential expenses, preserve savings, and fund creative work deliberately. Treat speculative income as uncertain until realized. The planner is an estimation tool; it does not guarantee financial outcomes.
